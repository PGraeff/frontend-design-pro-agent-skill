# Security Policy

## Supported version

Security fixes are applied to the latest release and the `main` branch.

## Reporting

Do not publish suspected vulnerabilities, malicious prompt instructions, unsafe installer behavior, exposed credentials, or supply-chain concerns in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/PGraeff/frontend-design-pro-agent-skill/security/advisories/new). Include the affected file or release, reproduction steps, likely impact, and a suggested mitigation when available.

The project does not intentionally collect telemetry, credentials, or user data. The runtime search tooling is local and uses the Python standard library.
